# Simple HTTP Server on C

Минималистичный многопроцессный HTTP-сервер на чистом Си под Unix-подобные системы. Проект разработан как лабораторная работа по книге *Beej's Guide to Network Programming*.

## Особености архитектуры
* **Unix-way:** Использование `fork()` для обработки каждого нового подключения в изолированном дочернем процессе.
* **Автоматическая очистка:** Корректная обработка зомби-процессов через `sigaction` и `SIGCHLD`.
* **Маршрутизация POST-запросов:** Реализована расширяемая таблица роутинга на структурах для обработки `POST` с довызовом `recv()` по `Content-Length`.
* **Модульная структура:** Четкое разделение сетевой логики (сокетов) и бизнес-логики эндпоинтов.

## Структура папок
* `/src` — исходный Си-код сервера
* `/include` — заголовочные файлы (.h)
* `/public` — фронтенд (HTML/JS) для тестирования POST-методов

## Сборка и запуск локально
Для сборки необходим настроенный `CMake`:
```bash
cmake .
make
./server
```

## Запуск в Docker (Alpine)
Проект полностью контейнеризирован и собран на базе ультра-минималистичного образа Alpine Linux:
```bash
docker build -t c-http-server .
docker run -d -p 8080:8080 --name my_server c-http-server
```
Сервер будет доступен по адресу `http://localhost:8080`.
